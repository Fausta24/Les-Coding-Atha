Input Element

Elemeent input html sering digunakan dalam pembuatan form di HTML. Element input bisa ditampilkan dalam berbagai cara tergantung atribut type.

Type Deskripsi
Type= "text" Menampilkan satu baris teks input (bisa menginpputkan lebih dari satu jens tipe data.).
Type= "radio" Menampilkan radio button (untuk memilih satu dari banyak pilihan)
Type= "submit" Menampilkan tombol submit atau kirim (untuk mengirimkan data dalam form)
Type= "checkbox Menampilkan checkbox (untuk memilih nol atau banyak pilihan sekaligus)
Type= "button" Menampilkan tombol yang dapat di klik.
Type= "number" Hanya bisa menampilkan inputan berupa angka
Type= "password" Menampilkan bintang dari inputan ke password
Type= "text area" Menampilkan area teks yang dapat diubah ukurannya untuk input teks yang lebih panjang
