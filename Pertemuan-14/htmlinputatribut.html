HTML Input Atribut

Kali ini kita akan menjelaskan perbedaan atribut untuk element input html.

  1. Value atribut

    Value atribut pada element input menentukan nilai awal untuk sebuah bidang input.

  2. Readonly atribut

    Atribut readonly pada element input menyatakan bahwa bidang input bersifat hanya dibaca Bidang input yang hanya dibaca tidak dapat diubah (namun pengguna tetap bisa menavigasi, menyorot, menyalin text). Nilai dari bidang input yang hanya dibaca, akan dikirimkan saat formulir di submit.

    Contoh:



  3. Disabled

    Atribut disabled pada element input menyatakan bahwa bidang input harus di non-aktifkan. Bidang input yang dinon-aktifkan, tidak dapat digunakan dan tidak dapat di-klik. Nilai dari bidang input yang dinon-aktifkan, tidak akan dikirimkan saat formulir di submit.



  4. Required

    Atribut required menyatakan bahwa bidang input harus diisi sebelum mengirimkan formulir. Atribut required bekerja pada tipe input berikut : Text, search, url, tell, email, password, date-picker, number, checkbox, radio, dan juga file.
