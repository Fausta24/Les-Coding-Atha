HTML Form Atribut

Kali ini kita akan membahas beberapa atribut penting pada elemen form di HTML.

  1. Action Atribut

    2. Action atribut sendiri menentukan tindakan yang akan dijalankan saat form dikirimkan. Biasanya, data form dikirim ke sebuah berkas di server ketika pengguna mengklik tombol submit. Contoh penggunaan atribut action adalah :



  2. Atribut Target

    3. Atribut target menentukan dimana respon yang diterima setelah mengirimkan form akan ditampilkan. Atribut target dapat memiliki beberapa nilai, diantaranya:

    Value Description
    _blank Respons ditampilkan di jendela atau tab baru.
    _self Respons ditampilkan di jendela saat ini.
    _parent Respons ditampilkan di frame induk.
    _top Respons ditampilkan diseluruh badan jendela.
    Framename Respons ditampilkan di iframe bernama
  3. Atribut Method

    4. Atribut method menentukan metode HTTP yang akan digunakan saat mengirimkan data form. Data form dapat dikirim sebagai variabel URL (dengan method="get") atau sebagai transaksi HTTP POST (dengan method post.) Metode HTTP default saat mengirimkan data form adalah GET.
