HTML Form ELement

Menjelaskan perbedaan element html yang digunakan di dalam teks form. Element form html dapat membungkus lebih dari satu element.

  • input

    • Element input adalah yang paling sering digunakan dalam pembuatan form di html. Element input dapat ditampilkan dalam berbagai cara, tergantung dari atribut type nya. Contoh :


  • label

    • Element label mendefinisikan label untuk beberapa element form. Element label berguna bagi pengguna screen reader karena screen reader akan membacakan label ketika pengguna memfokuskan element input. Element label juga membantu pengguna yang kesulitan mengklik area yang sangat kecil (seperti tombol radio aatau kotak centang). Atribut for pada tag label harus sama dengan atribut id pada element input untuk menghubungkan keduanya.

    • Element select mendefinisikan drop down list. Contoh :

    Element option mendefinisikan daftar pilihan yang bisa dipilih. Secara default, item pertama di dalam dropdown list akan dipilih. Untuk menentukan opsi yang dipilih sebelumnya, tambahkan atribut selected pada element option.

  • textarea

    • Textarea mendefinisikan bidang yang dapat menginputkan banyak baris data.
